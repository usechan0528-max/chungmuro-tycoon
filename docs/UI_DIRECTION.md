# UI Direction

ChungmuroTycoon의 UI 톤은 현실적 산업 시뮬레이션을 기준으로 한다. 플레이어는 캐릭터를 꾸미는 캐주얼 게임 화면이 아니라, 영화사 운영자가 매월 받아보는 산업 보고서와 제작 관리 화면을 읽는 느낌을 받아야 한다.

## Reference Tone

- Football Manager식 데이터 중심 운영 화면
- Civilization식 장기 전략 판단과 연표 감각
- 제작사 내부 보고서, 투자 검토서, 배급 전략 문서에 가까운 문장 톤
- 과장된 보상 연출, 밝은 캐주얼 카드 UI, 장난스러운 카피는 사용하지 않는다

## Layout Rules

- 첫 화면 이후의 핵심 화면은 대시보드, 표, 리스트, 지표 패널, 보고 문장 중심으로 구성한다.
- 화면 제목은 짧고 기능적이어야 한다. 예: `개봉 정산 보고서`, `제작 진행 보고`, `언론/평론 리포트`.
- 지표는 한 화면에 비교 가능하게 배치한다. 장식보다 스캔 가능성을 우선한다.
- 중요한 선택지는 버튼으로 남기되, 선택 결과는 숫자 노출보다 보고 문장으로 설명한다.
- 배우/감독 화면은 내부 스탯 숫자를 직접 보여주지 않고 공개 프로필 문장과 신뢰도 중심으로 표현한다.

## Visual Rules

- 기본 팔레트는 차콜, 저채도 청회색, 은은한 회색 경계선이다.
- 강조색은 제한적으로만 사용한다. 수익, 위험, 역사 이벤트 같은 상태 구분에 쓰되 화면 전체를 한 색으로 밀지 않는다.
- 둥근 카드형 장식은 최소화하고, 얇은 경계선과 촘촘한 행간의 리포트형 패널을 사용한다.
- 큰 히어로 타이포그래피나 캐주얼 게임식 보상 연출은 피한다.
- 기본 배포본에서는 실제 인물 사진을 포함하지 않는다. 배우, 감독, 평론가 이미지는 silhouette placeholder를 기본값으로 사용하고, 사용자가 `assets/media/`에 로컬 패치 파일을 넣으면 해당 이미지로 교체한다.
- 실제 영화 포스터 이미지도 기본 제공하지 않는다. 영화 정보는 제목, 제작진, 흥행 수치, 텍스트 리포트 중심으로 표현하며, 로컬 포스터 패치가 있으면 상세 화면에서 함께 표시한다.

## Writing Rules

- 문장은 건조하고 산업적인 톤을 유지한다.
- 결과 문장은 “대박!”, “흥행 신화!” 같은 과장보다 손익, 평판, 시장 반응, 리스크 변화를 설명한다.
- 이벤트 선택지의 내부 수치는 UI에 그대로 노출하지 않는다.
- 역사 이벤트는 “발생했다”보다 “시장 구조가 변화했다”는 식으로 장기 시뮬레이션의 원인과 효과를 드러낸다.
